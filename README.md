Daftar Kehadiran Siswa SMK Mandala
Deskripsi Singkat
Proyek ini merupakan aplikasi Python sederhana yang digunakan untuk mencatat kehadiran siswa di SMK Mandala. Program ini menampilkan daftar siswa yang sudah terdaftar dan memungkinkan pengguna untuk mencatat siapa saja yang hadir berdasarkan input nomor urut mereka.

Latar Belakang Ide
Kehadiran siswa adalah aspek penting dalam administrasi sekolah. Banyak sekolah masih menggunakan sistem manual (buku tulis) untuk mencatat kehadiran harian siswa, yang dapat menyulitkan rekap dan pelacakan data. Oleh karena itu, dibuatlah aplikasi sederhana berbasis Python untuk mempermudah guru atau petugas administrasi dalam mencatat kehadiran siswa secara digital dan praktis.

Manfaat Aplikasi
Mempermudah proses pencatatan kehadiran siswa
Mengurangi potensi kesalahan pencatatan manual

Penggunaan
Program akan menampilkan daftar siswa dengan nomor urut.
Masukkan nomor siswa satu per satu untuk mencatat siapa yang hadir.
